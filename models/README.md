# Mô hình cơ thể người 3D

`body.bin` và `body.json` được tạo từ dữ liệu **BodyParts3D** (bản 3.0, giảm 99 % đa giác),
© The Database Center for Life Science (DBCLS), phát hành theo giấy phép
[Creative Commons Attribution-Share Alike 2.1 Japan](https://creativecommons.org/licenses/by-sa/2.1/jp/deed.en).

Nguồn gốc: https://dbarchive.biosciencedbc.jp/en/bodyparts3d/

Các thay đổi: chọn lọc da, bộ xương, tim và mạch máu lớn, não, hệ hô hấp, hệ tiêu hoá;
giảm thêm số đa giác bằng gom đỉnh theo lưới; lượng tử hoá toạ độ 16 bit.
Công cụ chuyển đổi: `tools/bp_build.js`.
